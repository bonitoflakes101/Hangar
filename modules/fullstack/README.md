# fullstack

A typical web-app stack: VPC with three subnet tiers (public / private-app / private-db), an ALB in public, ECS Fargate tasks in private-app, and an RDS instance in private-db. The DB password is generated by Terraform, stored in **Secrets Manager**, and injected into the container as the env var `DB_CREDENTIALS_JSON`. Use this when your app needs a database and you want a clean three-tier topology to point at in interviews and reviews.

## Architecture

```
                Internet
                   │
                   ▼
         ┌─────────────────┐
         │  ALB (public)   │ :80
         └────────┬────────┘
                  │
                  ▼
         ┌─────────────────┐         outbound only
         │  ECS Fargate    │  ──── via NAT Gateway ──→ Internet
         │  (private-app) │ :container_port
         │   container    │
         │   env: DB_HOST │
         │   secret: ...  │ ◀──── Secrets Manager (DB_CREDENTIALS_JSON)
         └────────┬────────┘
                  │ TCP db_port
                  ▼
         ┌─────────────────┐
         │  RDS (private-db)│
         │  - encrypted     │
         │  - not public    │
         └──────────────────┘
```

Three security groups:

- `alb-sg`: :80 from `0.0.0.0/0`
- `app-sg`: container port from `alb-sg` only
- `db-sg`: db port from `app-sg` only

The DB is **not** publicly accessible. The only path in is through the app.

## Usage

```hcl
module "stack" {
  source = "../../modules/fullstack"

  name            = "my-stack"
  container_image = "nginx:alpine"
  container_port  = 80

  db_engine         = "postgres"
  db_engine_version = "16.3"
  db_name           = "appdb"

  tags = { Project = "my-stack" }
}
```

Inside the container, your app gets:

| Env var | Source | What it contains |
|---|---|---|
| `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER` | plain env | Connection details. |
| `DB_CREDENTIALS_JSON` | Secrets Manager | A JSON string — `{"username":"...","password":"...","engine":"...","host":"...","port":5432,"dbname":"..."}`. Parse it in your app to get the password. |

## How to deploy and test this

### 1. Prerequisites check

```sh
terraform -version
aws --version
aws sts get-caller-identity
```

### 2. Edit the example

```sh
cd examples/fullstack
```

Open `main.tf`. Change `name` so resources are namespaced. Defaults use `nginx:alpine` so the stack is deployable end to end without needing your own image.

### 3. Init, plan, apply

```sh
terraform init
terraform plan
terraform apply       # type: yes
```

Apply takes ~10–15 minutes. Most of it is RDS provisioning.

### 4. Verify

```sh
URL=$(terraform output -raw alb_url)
curl -i $URL                          # nginx page = ALB → ECS path works

# Inspect the DB secret (this is what your app gets in DB_CREDENTIALS_JSON)
SECRET=$(terraform output -raw db_secret_name)
aws secretsmanager get-secret-value --secret-id $SECRET --query SecretString --output text

# Watch app logs
LOG_GROUP=$(terraform output -raw log_group_name)
aws logs tail $LOG_GROUP --follow
```

To prove the DB is reachable from the app subnet, swap `nginx:alpine` for an image that connects on startup (e.g. one of your own apps that reads `DB_CREDENTIALS_JSON`). The networking is already wired up.

### 5. Destroy

```sh
terraform destroy     # type: yes
```

**Destroy takes 10+ minutes** — RDS shutdown is slow. Do not Ctrl+C. If you set `deletion_protection = true` you must disable it and re-apply before destroy will work.

## Cost warning

| Service | Free tier? | Approx cost if left running 24h |
|---|---|---|
| **RDS db.t4g.micro (postgres)** | 750 hrs/mo free for 12 months on a *new* account | ~**$0.40/day** outside free tier |
| **NAT Gateway** | **No** | ~**$1.10/day** |
| ALB | No | ~$0.55/day |
| Fargate (256 / 512) | No | ~$0.25/day per task |
| Secrets Manager | No (1 secret = $0.40/mo) | ~$0.013/day |
| RDS storage (20 GB gp3) | 20 GB free for 12 months | ~$0.08/day outside free tier |

**Total: roughly $2.40/day if left running outside free tier.** This is the most expensive architecture in the repo. Always destroy when finished.
